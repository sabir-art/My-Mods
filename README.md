# My Mods

Mods personnels pour Claude Code.

| Mod | Rôle |
|---|---|
| [conso](conso/) | Panneau minimaliste : coût, contexte, tokens, cache et limites du compte de la session. Commande `/conso`. |

## Installation

Dans une session Claude Code (terminal) :

```
/plugin install conso --marketplace sabir-art/my-mods
```

Depuis un shell :

```
claude plugin install conso --marketplace sabir-art/my-mods
```

Dans l'application de bureau : bouton **+** à côté de la zone de saisie → **Plugins** → **Add marketplace** `sabir-art/my-mods` → **Add plugin**.

Le panneau s'affiche dans le terminal, l'onglet Code de l'application de bureau (session locale) et l'extension VS Code. Dans une session cloud, `/conso` répond par un résumé texte.
