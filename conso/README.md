# Conso

Panneau minimaliste qui suit la consommation de la session en cours : coût total, remplissage du contexte, tokens cumulés en entrée et en sortie, lectures et écritures du cache avec leur taux de réussite, détail du dernier tour et limites du compte (5 h, 7 jours) avec leur prochaine remise à zéro. Une ligne de statut compacte reprend l'essentiel. Commande `/conso` pour rouvrir le panneau.

## Installation

```
/plugin install conso --marketplace sabir-art/my-mods
```
