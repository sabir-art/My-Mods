# Équipes

Panneau qui donne une vue d'ensemble des conversations d'équipe étiquetées `property-explorer` : celles qui travaillent, celles qui attendent une revue, celles qui ont terminé ou échoué, avec la tâche en cours, le modèle et le remplissage du contexte de chacune, plus un lien pour l'ouvrir. Une section suit aussi les sous-agents lancés dans la session courante et leurs tokens. Commande `/equipes` pour ouvrir le panneau, actualisation automatique toutes les deux minutes.

## Installation

```
/plugin install equipes --marketplace sabir-art/my-mods
```
